# Microsoft Office 产品图标素材

`microsoft-20251117/` 来自 Microsoft 官方 Office CDN 的固定版本。`sources.json` 记录逐文件 URL、下载时间、大小和 SHA-256；13 个文件均为 SVG 路径／渐变，没有嵌入位图。Word、PowerPoint、Excel 提供 16／32／48 尺寸，Office 和 Microsoft 365 提供 16／48；官方没有对应 32 文件，未自行伪造。

- [Fluent 官方图标指南](https://fluent2.microsoft.design/iconography/)
- [Microsoft Office 图标使用说明](https://learn.microsoft.com/en-us/microsoft-365/cloud-storage-partner-program/online/branding)

这些是 Microsoft 产品标识，不能按本项目的开源许可证重新授权；保留原色、比例与造型，仅用于实际功能性的 Microsoft 应用接入入口，不作为 Equation Lab 自有品牌或 Microsoft 背书标记。产品图标与 MIT 许可的 Fluent System Icons 是不同素材类别。

拟定映射：独立的多产品管理入口使用 Microsoft 365 图标；Word、PowerPoint、Excel 上下文使用对应产品图标与名称。当前实际接入仅 Word，其余图标属于后续设计预留，不意味着实现了对应宿主功能。
