# 图片识别

0.6.0 先把 MathType 公式的编辑、排版和 Word 回存做好。图片 OCR 留作后续功能，计划按需开启：粘贴图片、识别为 LaTeX，核对修改后再插入 Word。

识别模型与运行组件会一起处理，用户不需要自行配置 Python。模型选择前先比较识别准确率、修改时间、启动速度、内存和下载大小。

OCR is planned as an optional feature after the current editing and Word workflow. The intended flow is image → LaTeX → review and edit → insert into Word. It is not included in 0.6.0.
