# 版本记录

## 0.6.0

- 文档中的公式列表、搜索、切换和原位置回存。
- 编号格式预设、自定义输入、实时预览和文档编号详情。
- 修正求和上下限、根号、积分、数学减号及公式边缘裁切，提升预览清晰度。
- Word 跳转后的公式显示刷新；编号和交叉引用更新。
- 新增三节三十公式的 Word 和 PDF 演示。
- 简化安装、使用和开发说明。
